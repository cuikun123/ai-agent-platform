## 模块依赖关系

```
controller → service → repository（数据库操作）
                 ├──→ tool（工具执行，不调 service 防循环）
                 ├──→ agent（编排，通过 service 调度）
                 └──→ mcp（MCP Client，工具注册到 tool）
```

- service 是核心调度层
- tool 层不调用 service（防止循环依赖）
- agent 通过 service 完成编排
- mcp 发现的工具注册到 tool，被 service 统一调用

## 核心数据流

### 对话流
```
用户消息 → Controller → Service → ChatClient
    → Advisor 链（记忆注入 + RAG 检索）
    → LLM 流式返回 → SSE 推送前端
```

### RAG 流
```
文档上传 → 切片 → Embedding 向量化 → PGVector 存储
用户提问 → ChatClient → QuestionAnswerAdvisor
    → 向量检索 + 全文检索（混合，权重 0.7:0.3）
    → 注入上下文 → LLM 生成带引用的回答
```

### 工具调用流
```
用户提问 → ChatClient → LLM 决策调用工具
    → @Tool 方法执行 → 结果回传 LLM → 二次推理 → 回答
```

## 技术选型

| 层 | 技术 | 选型理由 |
|----|------|----------|
| 后端框架 | Spring Boot 3.4 | 企业级标配 |
| AI 框架 | Spring AI 1.0 | 统一抽象，支持多模型 |
| 数据库 | PostgreSQL + PGVector | 一套数据库搞定关系+向量+全文检索 |
| 缓存 | Redis | JWT 黑名单 + 令牌桶限流 + 会话列表缓存 |
| 前端 | React 18 + Arco Design | 组件丰富，适合管理后台 |
| 状态管理 | Zustand | 轻量，API 简洁 |
| LLM | DeepSeek V3 | 性价比高，OpenAI 兼容协议 |
