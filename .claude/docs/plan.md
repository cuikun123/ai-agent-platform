## 迭代二：对话模块

### 大方向
- Spring AI 接入 DeepSeek
- 流式对话（SSE，5 种事件类型）
- 会话管理（创建/列表/切换/删除）
- 对话历史持久化（ChatMemory）
- 多模型切换（ChatModel 抽象层）
- Token 计算与上下文截断
- 对话限流（Redis 令牌桶，30次/分钟）
- 前端对话页（流式渲染、消息气泡、停止生成、重新生成）

### 验收标准
- 能流式对话，逐字显示
- 刷新页面对话历史还在
- 切换模型生效
- token 超限自动截断
- 断网后错误提示正确

## 迭代三：RAG 知识库

### 大方向
- 文档上传（PDF / Word / Markdown / TXT）
- 智能切片（纯段落 vs 滑动窗口 vs 递归字符，对比实验）
- 向量化 + PGVector 存储（HNSW 索引）
- 混合检索（向量相似度 + PostgreSQL 全文检索）
- 引用溯源（回复标注来源：文档名 + 页码 + 切片片段）
- 多知识库关联对话
- 前端知识库页面（列表、详情、切片预览、检索效果对比）

### 验收标准
- 上传 PDF → 提问 → 引用原文回答
- 能在前端对比不同切片策略和检索策略效果
