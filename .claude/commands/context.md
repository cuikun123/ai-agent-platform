# /context — 切换迭代

## 触发时机

当前迭代完成（/review 全部通过）后，切换到下一个迭代。

## 参数

用户指定目标迭代，如：`/context 迭代三`

## 执行步骤

1. 读取 `docs/plan.md`（找到目标迭代的大方向和验收标准，已预先写好）
2. 清空 `docs/state.md`，写入新迭代的标题
3. 提示用户："已切换到 [迭代名称]，大方向如下：[列出]，请用 /plan 开始拆任务"

## 输出

用户看到：切换确认 + 新迭代的大方向
文件更新：state.md（重写）

## 注意

- plan.md 中所有迭代的大方向和验收标准在初始时已写好，/context 不需要再写入
- plan.md 只追加具体任务，不删除历史迭代的数据
- state.md 清空重写，只保留当前迭代
